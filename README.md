
# 🚀 Smart Sales Predictor

An AI-powered full-stack web application that predicts sales and helps businesses make better decisions using real-time analytics.

---

## 🧠 Features

- 🔮 Real-time Sales Prediction
- 🔁 What-if Scenario Analysis
- 💰 Price Optimization
- 📊 Interactive Dashboard
- 📁 CSV Bulk Prediction
- 🔐 User Authentication (Login/Register)
- 🌙 Light/Dark Mode UI

---

## 🛠️ Tech Stack

**Frontend**
- HTML, CSS, Bootstrap
- JavaScript (Fetch API)
- Chart.js

**Backend**
- FastAPI (Python)

**Machine Learning**
- Random Forest Regressor (scikit-learn)

---

## ⚙️ How It Works

1. User inputs price, discount, promotion
2. Data sent to FastAPI backend
3. ML model predicts sales
4. Results displayed in UI
